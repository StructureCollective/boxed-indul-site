What's New

"Notify Signups" Now Targets Your Filter

The Notify Signups button on each lunch event used to email everyone on your full signup list. Now it only emails whoever matches the filter selected in the Notify‑Me Signups table — so you can reach just one business (like USPS) without messaging your entire list by accident.

The admin dashboard's Events and Notify‑Me Signups cards, shown with sample data.

How It Works

1 Set the Notify‑Me Signups filter to the group you want to reach — a specific job or location, or "All" for everyone.
2 Click Notify Signups on any event card. It only emails whoever matches that filter right now — the confirmation message tells you exactly who it went to.

Accounts flagged as Admin (like yours) always appear in every filtered view, so you never lose sight of your own signups no matter what filter is selected.

What's New

New Sign-Up Forms, By Location

Each drop-off business now has its own private sign-up page — USPS, Toyota, and Police Station each get a unique link that isn't listed anywhere on the public site, so only people you hand a flyer or QR code to can find it. Every one of those pages, plus the general "Get Notified" form, requires a name and phone number now, with an SMS consent notice up front.

No matter which page someone signs up on, it lands in the same place: the Notify‑Me Signups table shown above, automatically tagged with the business it came from. That tag is exactly what the job filter — and the "Notify Signups" button — reads from.
